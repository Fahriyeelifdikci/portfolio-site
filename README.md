## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/Fahriyeelifdikci/portfolio-site.git
```

Go to the project directory:

```bash
cd portfolio-site
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

## 📦 Production Build

To create an optimized production build:

```bash
npm run build
```
